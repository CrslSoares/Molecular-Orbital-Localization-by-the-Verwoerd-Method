# Molecular-Orbital-Localization-by-the-Verwoerd-Method
This project aimed, by the Verwoerd method, to build a calculation algorithm to obtain the appropriate parameters to spatially estimate the localized molecular orbitals (LMOs) of the methane molecule and, more broadly, to propose generalizations for other molecules (of the group of homogeneous chain alkane hydrocarbons).

The main use of LMOs, according to Verwoerd (1979), includes:

• Facilitate the interpretation of Molecular Orbitals (MOs) calculations in the context of chemistry;

• Find orbitals that can be transferred from one molecule to another with similar atomic behavior;

• Minimize the effects of inter-orbital correlations;

• Calculate wave functions in large systems.
